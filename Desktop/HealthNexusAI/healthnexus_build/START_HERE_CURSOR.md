# Start Here — Cursor

1. Open this folder in Cursor.
2. Open Terminal → New Terminal.
3. Run the setup commands in README.md.
4. After the app opens, test the two user journeys:
   - Health Risk Assessment
   - Ask Health AI
5. Then run pytest and the Level 3/evaluation commands.
6. Only after the public dataset is confirmed should you use the metrics/results in your assignment.
